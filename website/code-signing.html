Code signing policy

Last updated 14 September 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Snowball Client launcher installers for Windows (SnowballClient-*-setup.exe and SnowballClient-*-portable.exe). They are built from the public source code at github.com/met4a/snowball-client by GitHub Actions, and only those builds are signed.

Team roles

  • Committers and reviewers: met4a
  • Approvers (release signing): met4a

All team members use multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. To install and run Minecraft it connects to Microsoft and Xbox services for sign-in, and downloads game files, Java, mod loaders and mods from Mojang, FabricMC, QuiltMC, MinecraftForge, NeoForged and Modrinth. See the privacy policy for details.

Uninstalling

The installer version can be removed from Windows Settings > Apps. The portable version is a single file you can delete. Game files and settings live in %APPDATA%\SnowballClientLauncher.
