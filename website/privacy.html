Privacy Policy

Last updated 27 September 2026

This policy explains what the Snowball Client launcher and the Snowball Client mod do with your information. In short: we do not run accounts, analytics or tracking. The only things that reach Snowball's own server are listed below, and they are there so chat and Snowball badges work.

Information we do not collect

Snowball Client does not send us your email, password, access tokens, gameplay, settings, logs, files or any usage statistics.

Snowball's server

Snowball runs one small server for the launcher's chat and for Snowball badges. It receives:

  • When you use the chat: your Minecraft name and account ID, proved with the public key Mojang issued to your account, and the messages you send. The last messages, mutes and ranks are kept so the chat works for everyone.
  • While you play with Snowball Client: every two minutes the game tells the server your Minecraft name and account ID, proved the same way, so other Snowball players can see your badge. Only that you are playing is kept, and it is forgotten within five minutes of the game closing. Switch it off under Menu & Accessibility, "Show others I use Snowball".
  • To draw other players' badges: the account IDs of the players the game can see, so the server can say which of them are playing with Snowball Client right now.

Your access token is only ever sent to Mojang, to fetch that public key; it never reaches Snowball's server.

Microsoft sign-in

  • You sign in on Microsoft's own login page. Snowball Client never sees your email password.
  • Microsoft gives the launcher sign-in tokens. They are used only to sign in to Xbox Live and Minecraft services so you can play.
  • The long-lived refresh token is stored on your computer, encrypted with your operating system's secure storage. Short-lived access tokens are kept in memory only.
  • Your Minecraft username and account ID are stored locally so the launcher can show your account.
  • Removing an account in Settings deletes its stored token. Microsoft's handling of your sign-in is covered by the Microsoft Privacy Statement.

Data stored on your computer

The launcher keeps instances, settings, logs, downloaded game files and account information in its data folder (on Windows, %APPDATA%\SnowballClientLauncher). Logs never contain passwords or tokens. You can delete this folder at any time.

Services the app connects to

To install and run the game, the launcher downloads files directly from these services, which receive your IP address as part of any normal web request:

  • Microsoft, Xbox Live and Minecraft services (sign-in)
  • Mojang (Minecraft versions, libraries, assets and Java runtimes)
  • FabricMC, QuiltMC, MinecraftForge and NeoForged (mod loaders)
  • Modrinth (Fabric API, optimisation mods, the mod browser, and the mod check, which sends only each mod's SHA-1 fingerprint, never the file)
  • Discord, on your own computer only, when Discord presence is switched on: never your account, your files, IP addresses or private server addresses

Each service handles requests under its own privacy policy.

This website

This website does not use cookies, analytics or third-party trackers. Our hosting provider may keep standard server logs, such as IP addresses and request times, for security and operation.

Children

Snowball Client does not knowingly collect information from anyone, including children. Microsoft's family settings apply to child Microsoft accounts.
