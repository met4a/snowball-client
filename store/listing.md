## Description

Snowball Client is a free launcher and client for Minecraft: Java Edition.

LAUNCHER
- Separate instances, each with its own version, mods, worlds and settings
- Built-in mod browser: search Modrinth, install in one click with dependencies, update with one click
- Always picks the mod version that matches the instance's Minecraft version and loader
- Fabric API added automatically to new Fabric instances
- Fabric, Quilt, Forge and NeoForge installed for you
- Java handled automatically
- Mod manager that catches duplicates and version conflicts
- Sign in with your Microsoft account on Microsoft's own sign-in page
- Crash detection and live game logs

IN GAME (press Right Shift)
- FPS Boost: pick Max FPS, Balanced or Quality with one switch; your own settings come back when you turn it off
- PvP HUD: direction compass, speed, combo counter, reach display, keystrokes, CPS, FPS and ping
- Visual tweaks: hit colour, block outline, low fire, no hurt shake, fullbright and a time changer that only changes your sky
- Chat upgrades: repeated messages stack, mentions of your name light up, right-click to copy a message, nick hider
- Camera: zoom, freelook, snaplook and a smooth third-person camera
- Type to search every module; every setting explains itself

Snowball Client only adds visual, interface and quality-of-life features. It has no hacks such as X-ray, ESP, reach, aim assist or auto clickers. Some servers do not allow client mods, so follow each server's rules.

You need a Microsoft account that owns Minecraft: Java Edition.

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.

## Notes for certification (Partner Center > Submission options)

Snowball Client is a launcher for Minecraft: Java Edition. On first launch it downloads the Minecraft game files from Mojang's official servers, a Java runtime from Mojang, and optional open-source mod loaders (Fabric, Quilt, Forge, NeoForge) and mods from their official sources, all verified by checksum. These downloads are the game the user already owns, not updates to the Snowball Client app itself. To test, sign in with a Microsoft account that owns Minecraft: Java Edition, create an instance and press Play.
